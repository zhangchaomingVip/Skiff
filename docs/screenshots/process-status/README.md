# 动态过程状态验证

2026-10-21。运行 `npm run dev -- --port 1421`，再执行 `node tests/process-status.browser.mjs http://localhost:1421`。浏览器脚本使用 Playwright（可通过 `SKIFF_PLAYWRIGHT_DIR` 指定安装目录），只访问独立预览和 mock transcript，不调用真实模型。

- 活动行显示当前动作与工具调用总数；同一 assistant 消息中的多个调用显示同一批次的完成进度，乱序结果和中间失败不轮播工具名称、不提示失败。
- 连续 10 秒无过程内容变化后追加当前动作的总运行时长，每秒更新；新的思考内容、工具参数或结果会立即隐藏时长。动作切换重新计时，完成和卸载清理计时器。
- 正文边界保留既有折叠组与计数冻结规则。完成后原地显示原有分项汇总，左侧保持静态星星，右侧为空。最终 `error` 才显示红色“失败”，摘要指明末批工具或模型响应环节；较早失败与恢复记录保留在展开详情。
- 当前动作仅使用受限字段：文件名、白名单程序与子命令、子代理名称。命令参数、搜索词、子代理任务原文和 URL 凭据不会进入动态标签。
- 运行中使用原有星星缓慢旋转和微光动画，结束恢复静态；系统减少动态效果时停用动画。图标与文字的布局间距为 4px。过程摘要不再提供原生 title tooltip，悬浮只显示紧邻文字右侧的箭头，不替换文字、不改变文字位置或颜色。键盘焦点也会显示箭头。
- 同一规则覆盖展开后的工具组、单个工具、思考明细和独立工具结果；展开或收起时箭头均默认隐藏，只有当前悬浮/键盘聚焦的行显示箭头。明细行移除成功时的“✓ 已完成”，保留执行中的提示、失败明细和文件增删计数；工具目标也不再提供 title tooltip。
- 过程明细容器不再添加左侧外边距；思考、工具组、单个工具展开后共用外层左边界，各层图标和文字列保持对齐，不随展开层级累积缩进。
- 单个命令、工具的展开内容使用主题适配的浅底色、细边框和圆角卡片，将命令/参数、文件差异与输出包在一起；独立工具结果也使用同一容器。卡片外沿保持左对齐，仅卡片内部增加阅读留白，工具组本身不套框。
- 卡片内部统一使用直接可见的区块标题，不再嵌套“调用参数”折叠行。长内容默认展示 12 行，可显示全部；文件与任务保留开头预览，命令输出保留末尾预览。子代理直接显示委派任务与代理名称；等待结果时仍保留任务内容。
- 每张工具卡片只保留一个复制入口：命令复制命令，edit 复制变更，write 复制写入内容，read 复制文件内容，搜索和其余已完成工具复制结果。复制始终使用完整内容，不受预览截断影响。
- edit 的差异和 write/read 的文件内容直接作为主区块，不再显示 oldText/newText/content 参数对象；未应用或失败的编辑标为“拟议变更”，错误仍单独展示。read 的行范围作为辅助信息保留。
- web_search 隐去与摘要行重复的 query 和引擎参数；按扩展现有的“标题/URL/摘录”格式解析来源。成功的搜索行显示“搜索网页（实际数量 个结果）”，默认是无边框的紧凑列表：左侧站点图标、中间单行标题、右侧域名，标题与域名过长时省略，整行可打开来源。只向来源站点请求 `/favicon.ico`，使用懒加载和无 referrer 策略，加载失败以域名首字母占位。长列表内部滚动，列表下方只保留一个复制入口，不显示摘要、摘录或相关展开入口；复制仍保留完整工具返回文本。链接只允许不含凭据的 HTTP(S)，异常格式保留可读文本，失败信息保留原有卡片样式。
- 思考内容使用单独的“过程记录”底色区域、小字号、弱化文字颜色与正文区分；外层思考行继续左对齐，不增加嵌套缩进。
- 每组展开详情先显示全部思考，再显示工具调用；思考之间、工具之间分别保留原顺序，工具组不重新合并。仅调整展示顺序，实时动作判断仍使用原始事件顺序，正文分段边界保持不变。
- Markdown 加粗继承父元素字号、行高和颜色，只增加字重；独立强调句、列表和引用均不提升为标题。只有语义 heading 获得标题字号，默认 h1 最高 18px、h2 最高 16px、h3–h6 同正文。用户自定义较大的正文时，标题不小于正文。

浏览器回归覆盖完整应用的浅/深主题预览、实时文案替换、5 工具并行进度、中间失败恢复、最终失败、Enter/Space 折叠、活动与完成行的 x/y/高度一致、停滞提示、390px 窄屏无横向溢出，以及计时器在结束/卸载后的清理。纯函数回归另覆盖时间阈值、时长累计与重置、脱敏、跨段最终失败归属。

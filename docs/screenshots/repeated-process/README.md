# 连续重复过程折叠

此目录保留上一版方案的截图。当前实现已替换为[两阶段过程折叠](../process-folding/README.md)，以下描述仅供历史参考。

预览入口：`http://localhost:1421/tests/preview.html?fixture=repeated-process&theme=light`，深色改为 `theme=dark`。使用 mock bridge，不调用真实模型。

连续至少三组「思考块 + 同类工具调用」默认合并为一行。跨助手消息识别，单条和多条调用均可计入同一类别；工具数按实际调用次数累加。正文、图片、用户消息、未匹配结果、混合类别工具组或类别变化会中断连续序列。空消息和空白正文不打断序列。未知工具按工具名称区分。

摘要右侧显示已完成、进行中、执行失败或未完成；进行中且已有失败时显示「进行中 · 有失败」。展开后保留每轮思考、工具分组、参数和输出，包含原本较短的思考。计数和详情随流式消息更新，原始消息与用量不变。

- `light-wide.jpg` / `dark-wide.jpg`：1440 × 1000，12 轮、24 条命令，其中一条失败。
- `light-narrow.jpg` / `dark-narrow.jpg`：600 × 900，无横向溢出。

交互验证：点击计数行展开 12 轮；展开工具组、单个工具并查看命令和输出；Space 收起计数行；Enter 展开；本轮总折叠隐藏计数行，再次展开恢复过程。浅深色主题均检查，`aria-expanded` 随折叠状态同步。

检查：`npm run build`、`npm run check:ui`、`npm run test:styles`、`npm test`。回归覆盖三轮阈值、跨消息与单消息重复、类别与正文边界、乱序结果匹配、原始数据保留、流式增长、失败和待返回结果、历史恢复与空回执。

# 供应商管理模型（配置 v6）

供应商在 `relays[].models[]` 直接保存真实模型 ID、家族、启用状态、图片输入、工具、流式、推理支持与等级、上下文、输出上限及价格。供应商总开关与模型开关独立；家族仅用于展示分组，原有展示清单与目录更新机制继续使用。价格相关汇率在供应商页设置。

`save_relay` 保存供应商及模型，不接收路线编辑列表。`list_model_runtime` 返回启用的具体供应商模型；pi 注册稳定的 `skiff-relay-<供应商 ID>`，模型 ID 保持供应商接口原值。同名模型在选择器中显示供应商名称。路线增删、排序和切换命令已移除。

聊天显式保存供应商与模型，新聊天仅继承当前有效选择。没有有效选择、配置读取失败、供应商停用或删除、模型停用或删除时保留原选择并阻止发送。请求错误不会改变选择；pi 对同一供应商模型的重试继续保留。模型详情中的推理等级是支持范围，每次聊天的推理强度仍在聊天界面设置。

运行时适配器按当前模型读取工具与流式开关。关闭工具会移除协议对应的工具声明。关闭流式时，Chat Completions / Kimi、Responses、Anthropic 发送非流式请求，再将完整回复转换为 pi 所需事件；Google GenAI / Vertex 改用 `generateContent` 端点，并将完整结果交回原 SDK 解析。Google SDK 不提供自定义 fetch，因此使用带私有随机标识的传输适配器，只处理标记过的请求，发送前移除内部标识；其余请求原样传递。协议转换、历史消息和计费仍由 pi SDK 处理。

## 旧配置迁移

首次读取 v3–v5 配置时，在内存中将路线模型移动到对应供应商，展开图片及推理等级继承。停用路线和剔除模型迁移为停用模型；供应商停用不会覆盖模型开关。重复且一致的模型合并兼容别名；任何配置差异都会报告冲突，保留原文件，不生成部分迁移结果。

迁移写入前原样备份 `skiff-families.pre-v6.bak.json`；已有备份与本次源文件不同则新增带唯一编号的备份。配置和 pi 投影沿用原子写入与失败回滚。无法解码、不支持的配置版本或迁移冲突都会保留原文件。

旧 `routeId` 和家族供应商键仅用于精确兼容匹配及历史展示，不参与调用排序。找不到匹配时不会跨供应商寻找替代。手动修改后的当前选择优先于最后一条历史回复；历史回复的供应商与价格快照保持原值，新回复保存当时的供应商、模型及价格，无需路线字段。

## 回归验证

- `cargo test --manifest-path src-tauri/Cargo.toml --lib`：继承展开、开关独立、重复合并与冲突、备份重试、迁移失败回滚、供应商模型投影。
- `npm test`：精确选择与兼容映射、历史费用快照、模型能力、显示清单及现有聊天行为。
- `node tests/pi.families.integration.mjs <pi-cli.js>`：隔离配置和本地服务，真实 pi 的同供应商多模型、图片及历史、独立价格和输出、工具、流式、401 与超时后选择不变。
- `node tests/pi.protocol-models.integration.mjs <pi-cli.js>`：Responses、Anthropic、Google GenAI、Vertex 中逐模型工具及流式开关实际作用于请求，回复与 token 统计正常，内部标识不出现在上游请求。
- `npm run test:cdp`：真实 WebView2 → IPC → Rust → pi，包含迁移备份、同名模型跨供应商精确选择、手动修改后重开、停用/恢复、删除和配置损坏时阻止发送、历史价格快照不变。沿用临时 agent 配置及全部 localStorage 备份与恢复。
- `npm run build`、`npm run check:ui`、`npm run test:styles`，以及 1421 端口浅深主题预览。

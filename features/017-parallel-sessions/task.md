# 多会话并行

生成期间可以从侧栏、主页、项目入口或 Ctrl+N 新建并切换会话。切走的会话继续运行，切回来复用原进程和实时消息；停止、错误、重连只作用于对应会话。

- 使用按聊天 ID 和项目目录区分的运行池，按访问启动独立 `usePiSession` / `PiRpc`，不预先启动全部历史会话。
- 将启动与清理的串行等待收敛到单个会话，避免某个卡住的启动阻塞其它会话。
- 会话自身保存文件索引、标题、模型、线路快照和耗时，后台完成也能持久化；应用侧线路授权和请求上下文按运行实例保存。
- 侧栏标记正在生成的会话，任务栏图标反映所有会话是否仍有任务。
- 导航与生成状态解耦；归档、删除以及移除项目仍检查目标会话是否空闲，避免误停后台任务。新聊天不会复用正在提交首条消息的草稿。
- 归档或删除后卸载对应运行实例，退出应用清理所有进程。已访问的未归档会话在本次应用运行期间保留进程；没有加入进程淘汰或跨应用重启续跑机制。

Rust 已经使用实例 ID 管理进程和事件，本次复用现有原生桥接，不增加权限或更改协议。

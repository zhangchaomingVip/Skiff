## 2. 项目上下文选择器

- [x] 在 Launcher 顶部显示当前项目名称和路径提示。
- [x] 复用 `useWorkspace` 的项目数据，实现切换项目和添加项目入口。

- [x] 创建聊天时把项目 ID、工作目录和选定 Offer 一起传给会话初始化。（`createChat` 已接受可选 `selectedModel`；Launcher 选定 Offer 的调用留在第 4 段）

验收：至少两个项目时可切换；新聊天在正确项目目录启动；已有聊天的项目归属不被修改；窄窗口仍可操作。

## 3. 动态模型目录与卡片

- [x] 使用 `modelFamilies.offers` 动态生成模型卡片，不写死家族和线路数量。
- [x] 按家族和模型聚合 Offer，同时保留默认线路、有效线路数量和线路选择入口。
- [x] 显示模型 ID、能力、上下文、输入/输出价格、线路和可用状态。
- [x] 覆盖加载中、无线路、配置错误和禁用线路状态。
- [x] 增加“最近使用 / 全部模型 / 搜索”入口，沿用现有 Offer 搜索语义。
- [x] 处理同名模型、多线路和重复别名的显示消歧。
- [ ] 外部 Agent 状态：当前运行时目录没有外部 Agent 数据源，暂不伪造卡片；待接入真实 Agent 状态后补充。

验收：同一模型的多条线路不会被错误合并成一个不可解释的选择；禁用线路不出现在可选线路中；模型卡片使用真实配置和价格；`npm run build`、模型相关 Node 测试通过。

## 4. 卡片启动与线路选择

- [x] 单线路模型点击“开始聊天”后直接钉住对应 `offerId`。
- [x] 多线路模型点击“选择线路”打开可搜索、可键盘操作的 Offer 浮层。
- [x] 浮层展示线路名、模型 ID、能力、价格和扣费账户状态。
- [x] 选择跨账户线路时，明确显示目标账户；不复用自动故障切换授权状态。
- [x] 创建聊天后进入聊天页，不自动发送任何文本。

验收：线路选择与聊天页 `ModelMenu` 使用同一套 Offer 标识；会话索引保存 routeId / modelId / offerId；跨账户选择没有静默行为；浏览器预览覆盖鼠标、键盘和 Escape。

## 5. 最近会话与历史线路

- [x] 在 Launcher 显示最近会话标题、项目、更新时间、模型和最后实际线路。
- [x] 点击最近会话后恢复原会话，不创建重复草稿。
- [x] 费用和 token 摘要只在有可靠数据时展示；缺失时不伪造数字。
- [x] 历史模型和线路显示优先使用 `RouteSnapshot`，不回查当前配置覆盖历史。
- [x] 对线路被删除、停用、改名和改价的历史会话做回归检查。（沿用既有 RouteSnapshot/workspace 测试）

验收：最近会话能准确恢复项目和聊天；历史线路、价格和费用在配置变化后仍保持快照语义；相关 workspace / route snapshot 测试通过。

## 8. 用量摘要与性能收尾

- [x] 评估是否为 `Conversation` 增加轻量 `usageSummary`，并明确其与消息级 RouteSnapshot 的关系；首版暂不增加，避免在没有可靠累计数据源时伪造摘要。
- [x] 确认不实现摘要时不改变现有索引校验；继续只展示已确认的消息级线路快照。
- [x] 避免 Launcher 每次渲染重新计算全部历史消息；模型聚合和筛选均按输入使用 `useMemo` 缓存。
- [x] 检查大模型列表和长会话切换时的渲染性能；Launcher 不读取或遍历会话消息，仅处理最多 8 条索引记录。

验收：没有可靠用量时 UI 仍稳定；有摘要时与消息级费用一致；没有引入密钥、请求正文或敏感 URL；相关 Node 测试通过。

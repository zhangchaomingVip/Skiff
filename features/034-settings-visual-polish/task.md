# 034 · 设置页视觉与信息整理

状态：已完成。创建日期：2026-11-24。验证见 [verification.md](verification.md)。

来源：对设置页的走查意见，参照了改前的浅色外观页截图、圆角内容卡片布局和活动栏样式两张参考截图（截图只用于本地比对，已删除）。本特性承接 016 统一设置入口和 019/020 设置信息整理。上述文档里出现的「字体」「快捷键」分类，以及「会话统计」「归档会话」这些名称，以本文为准。

## 背景与目标

设置页能用，但看起来散乱：导航和内容是两块并排的白色区域；字体、快捷键这两个分类内容很少；说明文字多数在描述实现细节；外观选项选中时会变成一张浮起来的卡片，导致布局跳动；活动栏选中时只靠一根贴边的竖条区分，进入设置后高亮的位置也是错的。

本次只调整信息结构、布局和组件视觉，不改设置的数据格式、原生命令或权限。

## 范围与行为约定

### 1. 清理（不改变任何外观）

- `App.tsx` 原来在 Code 和 Design 两个工作区各写了一遍 `<SettingsWorkspace>` 的完整参数，现在合并为一处定义的 `settingsWorkspace`，两个工作区共用。
- `index.css` 删除了同一层里互相覆盖的旧规则，以及永远不会生效的规则：`.settings-layout`、`.settings-content`、`.settings-workspace` 背景、`.settings-nav` 内边距和背景，还有分散在三处的窄屏 `@media`。另外删掉了没有对应元素的 `.settings-heading h1`、`.settings-nav p`。

### 2. 信息结构

- 字体并入外观页，作为「字体 / 字号」两行卡片。删除了字体分类、字体预览和「恢复默认字体」按钮（字号下拉里已经标出了默认值）。
- 删除快捷键分类和对应样式。设置入口的 tooltip 改为显示「设置（Ctrl/Cmd+,）」。
- 导航分为四组：通用（外观、对话）；模型与能力（供应商、系统提示词、联网搜索、AI 浏览器、图片生成、视频生成）；数据（对话统计、已归档对话）；最后一项「关于」单独放在末尾，不加组标题。导航的顺序由 `settingsCategories` 数组决定。
- 外观页的卡片依次为：主题模式与主题色 → 深色背景与显示星星（星星是深色背景的一部分，所以放在同一张卡片里）→ 字体。
- 精简说明文字：删掉了外观、联网搜索、对话、已归档对话、供应商几页的副标题，以及主题模式、主题色、显示星星三项的说明。AI 浏览器、图片生成、视频生成、系统提示词、标题模型的说明都压缩成一句话，不再出现 `pi`、`web_search`、`--append-system-prompt` 这类实现细节。「仅在深色模式下生效。」这句提示只在浅色模式下显示。
- 系统提示词、已归档对话两页套上 `settings-page`，供应商页标题的字号也和其他页统一。

### 3. 布局

- 打开设置时，外层工作区框（`.workbench-shell`）去掉边框和背景，导航直接显示在应用的背景上。内容区（`.settings-active`）单独做成圆角卡片，四周留出外边距。Code 和 Design 两个工作区共用这套样式，原来只给 Design 用的 `.settings-shell` 已删除。
- 设置导航宽度从 272px 改为 224px。「设置」标题从内容区移到导航里「返回工作区」的下方，内容区只保留各页自己的标题。
- 设置打开时，隐藏 Code/Design 切换、航行台、浏览器和侧栏开关，同时隐藏不起作用的侧栏宽度拖动条。

### 4. 组件

- 分段控件：去掉外框，背景改为中性的浅色底（`--segmented-track`），选中项用白底、细阴影和正文色（`--segmented-selected`），不再用强调色。鼠标悬停在已选中项上时保持选中样式。这个组件在全应用通用。
- Code/Design 切换改用同一套颜色。标题栏上的底色用 `--titlebar-segmented-track`（浅色下为半透明白），并去掉了两个图标。
- 主题色色块改为左对齐的弹性布局，宽度固定 76px。选中时只在色圆外加一圈强调色描边，并在右下角显示 ✓；不再出现背景卡片、阴影或上浮效果，任何状态下尺寸都不变。
- 设置行里的下拉框宽 200px，边框改用卡片的 `--border`。
- 星空黑和星空蓝两个主题有了自己的 `--settings-action` 色（`#40609a` / `#3f68a8`），不再借用全局按钮的饱和蓝。

### 5. 活动栏

- 宽度从 40px 改为 48px，按钮从 32px 改为 36px，圆角 10px，间距 6px（`--activity-button-size`、`--activity-radius`）。
- 去掉贴边竖条。选中项改为主题色 14% 的浅色块，图标显示为主题色。设置导航的选中项也用同一种浅色块。
- 「文件」图标改为新增的 `folderTree`。普通文件夹图标和展开的文件夹图标留给侧栏的项目行用；原来那个叠在一起的纸张图标容易看成「复制」。
- 设置打开时，只有齿轮显示为选中（`aria-pressed`），其他工具都不高亮。点活动栏上的任意工具会退出设置并打开对应面板，修复了原来点「文件」没反应的问题。
- 外观分类的图标改为 `palette`；`sun` 图标补上了中心圆。「返回工作区」的箭头改用 `arrowLeft` 线框图标。

### 6. 背景连续

- 浅色主题下，`.app-body`、`.titlebar`、`.activity-bar` 三处的渐变都固定到视口（`background-attachment: fixed`），这样标题栏、活动栏和设置导航之间看不出接缝。深色星空主题早就是这样处理的。

### 7. 全应用统一用「对话」

- 用户可见的文字和读屏用的 `aria-label`、`title` 里，原来的「聊天」「会话」统一改为「对话」，涉及 30 个文件。变量名、函数名和代码注释不改。收尾时补上了三处遗漏：项目的移出说明和计数、草稿的默认标题与工作区保存报错、上下文提醒里的「新开对话」。
- 两处故意保留原词：一是「pi 会话文件」「pi 会话目录」（指磁盘上真实存在的文件，删除确认时需要说清楚）；二是 `TITLE_PROMPT_MARKER`「生成一个简短的会话标题」（它既是发给模型的提示词，也是统计时用来识别标题请求的标记，改了以后历史记录就识别不出来了）。

### 8. 关于页

- 新增 `AboutSettings.tsx`，显示以下内容：
  - 品牌标识、版本号和 Tauri 版本（来自 `@tauri-apps/api/app`）；
  - 应用数据目录（`appDataDir()`），以及 pi 配置目录（复用 `get_pi_auth_status`，遵循 `PI_CODING_AGENT_DIR`）；
  - MIT 许可证。
- 三个复制按钮都只显示图标，tooltip 分别是「复制版本信息」「复制路径」。「复制版本信息」会复制三行：Skiff 版本、Tauri 版本和 userAgent。
- 在浏览器预览中，以上各项都显示为「—」。没有新增原生命令或权限。
- 「检查更新」和「日志位置」没有做：项目没有接入 updater，也不写日志文件，Rust 端只用 `eprintln!` 输出。

## 涉及文件

- 组件：`SettingsDialog.tsx`、`settingsNavigation.ts`、`FontSettings.tsx`、`AboutSettings.tsx`（新增）、`ActivityBar.tsx`、`TitleBarNav.tsx`、`WorkspaceModeSwitcher.tsx`、`Icon.tsx`。
- 样式：`index.css`、`tokens.css`、`components/ui.css`、`components/workspace-modes.css`。
- 其他：`App.tsx`、`theme.ts`（新增 `useResolvedTheme()`），以及统一用词涉及的侧栏、浏览器、航行台、统计、报错文案等文件。

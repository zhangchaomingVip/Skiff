## 未验证 / 已知边界

- 原生 Tauri/WebView、操作系统缩放与真实 pi 会话未执行（仅 mock bridge）。
- 工作目录行依赖工具 args 携带 `cwd` 类字段；pi 当前不传，故实际会话通常不显示该行，属诚实展示。
- Shell 名称对通用执行器（`exec`/`run` 等）按 `navigator.userAgent` 平台推断（Windows → PowerShell，其余 → Bash）；pi 自带的 `bash` 工具按工具名如实显示 Bash。
- Web 预览卡未实现（见验收第 4 条说明）。

## 评审与修复记录（GLM-5.3 max）

2026-10-25 由 GLM-5.3 最高推理档完成两轮独立审查（逐轮审查 + 换人终审），结论为无 blocker/major 问题、交付门禁全过；终审提出 7 条 minor 意见，已全部修复并复验：

2. 结果卡片可能在流式期间先于最终正文出现在当时的尾部消息上 → 卡片增加 `!turnRunning && !message.streaming` 门禁，轮次落定后一次性渲染。
3. 命令解析回退分支缺测试 → 补引号+分隔符、命令替换/反引号/`$` 变量、单 `&` 后台、三段管道、多行脚本、带引号 Windows 绝对路径共 9 个断言。

5. `tokens.css` 被改动的行缩进比相邻 token 少一级 tab → 恢复两级缩进，diff 现为纯新增两行。
6. delete 工具在过程组行显示“编辑了 N 个文件”，与删除结果卡同屏矛盾 → `toolRuns` 新增 `delete` 类别（“删除文件 / 删除了 N 个文件”+ trash 图标），混合运行按“编辑 N 个文件；删除 N 个文件”分列（`polish.test.ts` 新增用例）。
7. `diffCounts` 把统一 diff 的 `+++`/`---` 文件头行各多计 1 行 → 排除文件头（`turnResults.test.ts` 新增用例），`ToolCallBlock` 状态计数同步修正保持一致。

# 039 · 图片画廊与失败记录分离

状态：实现及隔离验证完成。创建日期：2026-11-12。

来源：失败记录堆积在图片作品前面，影响浏览；画廊图片需要移除入口。本期只调整图片工作区，视频任务页沿用现有行为。

## 行为

生图工作区提供三个独立视图，默认进入「作品」：

- **作品**：仅展示未移除的生成/导入图片，以及正在生成或保存的任务卡片。历史失败不占位置。
- **失败记录**：集中展示生成失败、已中断和停止等待的记录，保留状态、时间、服务/模型、尺寸、完整提示词及错误。默认摘要最多三行，展开「查看完整记录」后查看全文；可复用提示词，但不会自动重试。
- **已移除**：查看已从画廊移除的图片，点击「恢复到画廊」可还原。

三个入口显示各自数量。生成过程中失败时，只在作品页出现一条可关闭的状态提示和「查看失败记录」，不重新堆积长记录。用户在失败页复用提示词并生成时，会返回作品视图展示新任务；查看旧记录不会中断当前任务。

图片更多菜单和图片预览底部新增「从画廊移除」，生成图片与本地导入均可操作。采用可恢复的移除语义，不删除本机原文件、参考图快照、提示词或用量。已移除作品仍可预览和恢复；当前正在引用它的图生图/图生视频草稿继续有效。

生成作品的移除状态随任务持久保存，重载/重启后不回到作品页。本地导入仍只保留在本次应用运行期间，其移除与恢复状态同样仅在当前运行保留。

## 实现边界

- `ImageJob` 新增默认 false 的 `removed` 字段，旧任务缺少字段时视为正常展示。
- 新增 `set_image_generation_asset_removed(id, removed)`，只允许操作已完成的图片任务，校验 UUID 后更新对应记录。未知 ID、路径越界和未完成任务拒绝；不增加通用文件删除能力或权限。
- `useImageGeneration` 在原生命令成功后更新本地记录；通过读取版本保护，避免正在生成其他任务时，迟到的列表查询覆盖最新移除/恢复结果。
- `useGenerationStudio` 对导入图片保留运行期 removed 标记，不释放仍用于恢复或参考的共享 URL。
- 图片渲染区按视图过滤，作品计数只计未移除图片；失败记录保持独立，视频画廊不受影响。
- 操作后关闭选中的图片预览，焦点返回画廊视图控件；移除失败时保留原卡片和错误反馈。
- 复用既有 SegmentedControl、菜单、按钮与主题 tokens。窄窗导航换行、错误摘要和预览底部操作不会造成横向溢出。

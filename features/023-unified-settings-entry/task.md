# 023 · 主页面统一设置入口与视觉整合

状态：已实现，自动检查与模拟浏览器验收通过；原生环境未覆盖项见 [verification.md](verification.md)。创建日期：2026-10-17。

来源：[主面板原型](../../design/panel-settings-mockup.html)及[集成评估](../../design/panel-settings-integration-assessment.md)。本 feature 对应评估中的第一期，承接 009/020 的设计令牌与 UI 原语，保留 007 的线路选择、017 的多会话、018 的聊天交互和 019 的搜索与草稿能力。原型提供布局参考，行为以本任务约定和现有业务实现为准。

## 背景与目标

当前主页面顶栏同时放置主题、分享、系统提示词、设置和诊断日志；“设置”实际打开 `FamiliesSettings`，其中又包含供应商、模型线路与归档会话。全局偏好与当前会话操作的层次不够清楚。

本期把全局设置集中到左下角入口和统一设置面板，精简顶栏，同时保证侧栏折叠、窄窗和键盘场景都能找到设置。聊天工作流、模型线路身份、运行状态及配置保存流程保持现有语义。

完成后的核心路径：左下角“设置” → 选择分类 → 在同一个设置面板内完成操作；模型选择器中的“管理提供商”直达该面板的对应分类。

## 范围与行为约定

### 1. 设置入口与顶栏

- 左侧栏底部提供一个明确命名为“设置”的按钮，使用现有图标体系；副标签显示“当前会话：pi 已连接/未连接”，没有活动会话时显示“无活动会话”。连接状态来自活动 session，不代表所有后台会话或供应商 API 健康状况。
- 点击按钮打开轻量菜单，提供“外观”“模型与提供商”“归档会话”“快捷键”四个入口；每项直达设置面板对应分类，不添加仅 hover 可达的子菜单。
- 入口不以模型品牌命名，不给头像分配另一个不可完成的操作。当前模型仍在聊天区显示与选择。
- 侧栏展开时移除顶栏重复的设置入口和独立主题按钮；侧栏折叠时在顶栏提供“设置”按钮，直接打开统一面板的“外观”页。主页与聊天页都可访问。
- 保留顶栏后台会话汇总、当前运行状态、分享、系统提示词和诊断日志。系统提示词继续作用于当前会话，不改成全局设置。
- 保留 `TitleBar` 及窗口拖拽、最小化、最大化、关闭功能，保留侧栏折叠与宽度调整。
- 窄窗侧栏抽屉中选择设置分类时，先关闭侧栏抽屉再打开设置面板，避免两个导航模态窗口叠加；关闭设置后焦点回到可见的顶栏设置按钮。

### 2. 统一设置面板

| 分类 | 本期内容 | 数据与行为来源 |
| --- | --- | --- |
| 外观 | 跟随系统、浅色、深色 | 现有 `theme.ts`、主题初始化与持久化机制 |
| 模型与提供商 | 供应商与模型线路两个内部分类，保留现有配置功能 | `FamiliesSettings`、`useModelFamilies` 及原有保存回调 |
| 归档会话 | 查看、恢复、删除已归档会话 | `ArchivedSessions` 与 workspace 原有操作 |
| 快捷键 | 展示当前真实生效的快捷键及作用范围 | 当前事件处理逻辑与本期新增设置快捷键 |

- 桌面布局采用左侧分类、右侧内容，提供名称明确的关闭按钮。窄窗改为顶部分类选择或单列布局，内容可滚动，关闭与表单提交操作始终可达。
- 通用入口默认打开“外观”；定向入口直接进入目标分类。“管理提供商”默认定位供应商列表，不出现另一套设置窗口。
- 同一时刻只保留一个顶层设置面板实例。已有删除确认等业务对话框按原有流程保留，不能因拆分容器丢失确认、返回或焦点恢复。
- `FamiliesSettings` 的表单、测试、发现模型、价格导入、汇率、默认线路、启停、排序、故障切换等已有能力全部保留，不只迁移原型中的简化“管理”按钮。
- 外观选择即时生效，继续使用现有主题存储及原生窗口主题同步。修改主题不得触发聊天组件重挂载、清空草稿或重启 pi。
- 模型配置继续使用现有显式保存和错误提示，不新增全局“保存所有设置”。重开面板读取真实配置，不复制一份与业务状态脱节的数据。
- 配置编辑子页打开期间禁用外层分类切换，提供现有“返回列表/取消”动作；Esc 先执行当前编辑页的返回逻辑，再由后续 Esc 关闭设置。保存 pending 时遵守现有关闭保护，测试取消及迟到结果处理沿用原逻辑。
- 配置错误时保留错误信息和现有恢复入口，外观与快捷键分类仍可访问。
- 设置容器与外观、快捷键页在聊天运行时仍可打开；模型配置和归档操作保留原有 busy、navigationBusy、canClose 等限制，不因新增入口绕过保护。禁用分类或动作需说明原因，定向打开也走相同校验。

### 3. 键盘、焦点与弹层

- 新增 `Ctrl+,` 打开设置，macOS 使用 `Cmd+,`；在设置已打开时不创建重复面板，不打断编辑或提交。其他业务模态窗口打开时不抢占该窗口。
- 保留 `Ctrl+K` 聚焦输入框、现有新聊天快捷键、Enter 发送、Shift+Enter 换行和停止快捷键。快捷键帮助按实际平台与已有实现展示，不宣称未实现的平台组合键可用。
- 设置打开期间，后台聊天快捷键不得创建会话、聚焦输入框、清空草稿或触发停止等动作；输入法组合输入期间不执行新增全局快捷键。
- 本期不增加 `Ctrl+D/K/G` 切家族、`Alt+方向键` 切模型/推理，不引入原型的两次切家族确认。
- 复用 `ui.tsx` 的 `Dialog`、`Popover`、Button 等原语；菜单项和分类使用可聚焦的真实控件，提供名称、选中与展开状态。若使用 menu/tab ARIA 语义，同时实现其对应的方向键行为。
- 打开菜单或设置时聚焦合适控件；模态内 Tab/Shift+Tab 正确循环，Esc 只处理最上层交互；关闭后回到触发入口，入口因窄窗布局消失时回到可见备用入口。
- 弹层使用现有视口约束与翻转逻辑，不复制原型固定的 `left/bottom` 定位。折叠侧栏、改变宽度或窗口缩放后仍不裁切选项。

### 4. 视觉与现有功能边界

- 采用原型的区域层次、简洁入口与设置分类结构，颜色、字号、间距、圆角、阴影及动效使用 `tokens.css` 和现有层化样式。
- 必要说明与普通文字对背景至少 4.5:1；焦点清晰可见，选中状态有文字或图标辅助，兼容减少动效偏好。
- 延续现有可调侧栏宽度与窄窗断点，不固定为原型的 280px，不全量重写主页面 CSS。
- 主页保留 `LauncherView` 的模型目录、项目选择和最近会话；“新聊天”继续在当前项目创建空白草稿，两者不合并为同一操作。
- 输入区保留 `ModelMenu` / `ModelPicker` 的 Offer 选择及线路、账户、价格信息；`ReasoningChip` 继续按运行时等级渲染。第一期不拆成家族/型号滑杆，不改推理开关。
- 航行台、工具航迹、上下文、附件、联网、插话/排队、停止、会话搜索和草稿恢复继续留在原工作流中。累计用量与上下文容量不合并成原型的占位统计。

## 非目标

- 不重做模型选择器、推理控件或会话状态机，不修改 RPC、Offer 身份、线路授权与配置文件格式。
- 不新增语言切换、字号设置、CLI 路径编辑、自动恢复偏好、流式输出总开关、全局断连或累计用量页面；不展示可点击但未接通的占位设置。
- 不重做航行台、项目管理、搜索、草稿、消息渲染或主页模型目录。
- 不引入新 UI 依赖，不复制原型的全局变量、innerHTML 模板和 DOM 事件管理。
- 第二期聊天控件调整需另列任务，不作为本 feature 完成的前置条件。

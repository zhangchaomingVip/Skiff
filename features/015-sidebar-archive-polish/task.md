# 015 · 侧栏、会话归档与模型选择器优化

状态：已完成（2026-10-11）。

## 背景与目标

改善会话导航和聊天工作区的日常操作：最近会话区可以整体折叠；会话可以归档，并在设置中查看、恢复和删除；左右侧栏可以鼠标拖动调整宽度；聊天输入区的模型选择器只显示品牌图标、模型名和下拉指示。

归档应保留原有会话文件及会话元数据，不得把归档误作磁盘删除。归档查看为只读，恢复后才能继续对话。侧栏调整不能挤掉聊天主要区域，也不能改变窄窗口上的抽屉交互。

## 行为约定

- “最近”标题行作为折叠按钮，默认展开；独立记住其折叠状态，点击可收起或展开全部最近会话。
- 归档从侧栏会话行操作和右键菜单触发。归档记录从项目聊天列表及计数、侧栏搜索、“最近”和主页最近会话中排除。
- 归档当前打开的会话后返回主页，并在后台选择同项目最近的未归档会话；没有候选时创建空白草稿。
- 设置入口提供“归档会话”视图，支持按会话标题和项目搜索，并展示项目及归档时间。
- 归档会话提供查看、恢复和删除。查看打开只读会话预览，关闭后回到归档列表；恢复后关闭设置并进入会话；删除沿用现有确认操作，只从应用索引移除，保留 pi 会话文件。
- 只读预览显示消息、图片、思考过程及工具结果，支持复制；不得发送消息、修改模型、回退/编辑/重新生成/删除消息，也不得改写当前会话索引。
- 归档中的会话文件缺失时显示错误及重试入口，同时保留恢复和删除操作；没有消息的归档显示空状态。
- 左侧导航默认宽度为 240px，可调范围 200–420px；右侧航行台默认宽度为 260px，可调范围 240–480px。各自记住宽度，且拖动时聊天区最小宽度为 360px。
- 空间不足时临时收起右侧航行台，不覆盖已保存宽度。宽度随窗口可用空间限幅。窄窗口继续使用现有抽屉和弹窗，不显示调宽把手；诊断日志栏不纳入调宽。
- 输入区模型按钮显示“品牌图标 + 模型名 + 下拉箭头”，不重复展示家族名；继续展示模型别名，无品牌图标时使用通用模型图标。完整模型和线路信息保留在悬停提示中，选择菜单行为不变。
- 归档、恢复和删除遵守现有忙碌限制；回调也检查当前状态，不能在生成或其他不可导航操作期间切换会话。

- [x] 在会话行操作和右键菜单添加归档命令；设置弹窗增加归档列表、项目/标题搜索、查看、恢复和删除入口。

验收：普通会话仅标记归档即可在整个常用列表中消失；恢复后回到原项目和普通列表；查看期间当前聊天、模型和索引不变；删除后索引条目消失且原 pi 文件仍保留。

## 实施默认值

- 沿用 workspace v1 与浏览器本地索引，不迁移 pi 会话文件。
- 归档查看采用只读预览；恢复是继续聊天的明确入口。
- 删除沿用“仅从侧栏/应用索引移除”的当前语义。
- 设置归档视图使用齿轮设置入口，不另设主导航页。
- 左右栏宽度仅在桌面侧栏模式生效并独立持久化；默认宽度和边界按本任务约定。

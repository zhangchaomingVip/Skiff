# 025 · 供应商独立配置入口

状态：已实现，自动检查与模拟浏览器验收通过；原生环境未覆盖项见 [verification.md](verification.md)。创建日期：2026-10-18。

来源：023 统一设置入口的后续拆解。023 把供应商与模型线路放在同一个「模型与提供商」分类里，用页内 tab 切换；本期把供应商拆成设置面板的独立分类，模型线路留在原分类，两页互不混装。

## 背景与目标

供应商（`RelaySpec`：端点 + 一条 API 密钥）与模型线路（`RouteSpec`：供应商 × 家族 × 模型/单价/能力）是两类配置对象，条数与编辑频率都不同，但此前共用一个分类和一个 tab 条，导致：

- 侧栏菜单、模型选择器、主页目录里的「管理提供商」都要先落到组合页，再靠默认 tab 猜位置；
- 保存供应商后跳回线路 tab 的提示与线路列表混在一起，删除供应商的确认文案与线路删除确认挤在同一页；
- 线路页在没有任何供应商时只能给出「去添加供应商」的页内切 tab，无法指向真正的入口。

目标：供应商成为设置面板的独立分类，两个页面各自只描述自己的对象，跨页只保留必要的回链。

## 范围与行为约定

### 1. 设置分类

- 分类顺序为：外观、联网搜索、系统提示词、供应商、模型线路、归档会话、快捷键；供应商使用现有图标体系中的 `anchor`，模型线路沿用原 `tokens`。
- 原「模型与提供商」标签改为「模型线路」，页内标题同步；页内 tab 条与 `供应商/模型线路` 切换按钮全部移除。
- 侧栏底部设置菜单自动跟随分类表，因此菜单里直接出现「供应商」与「模型线路」两项；通用入口仍默认打开外观。

### 2. 供应商页（新）

- 保留原有能力：供应商列表（图标、名称、掩码端点、已配置模型数、密钥指纹、启停开关、编辑入口）、添加供应商（预设目录 + 搜索 + 自定义供应商）、编辑器（名称、密钥、端点、扣费账户、超时）、连接测试与「测试所有模型（5 并发）」、慢响应阈值、剔除/恢复模型、删除确认。
- 新增供应商仍要求通过连接测试才能保存；保存时继续按发现结果自动为 DeepSeek、Kimi、GLM 生成线路（沿用 `buildDiscoveredRoutes` 与最新模型推荐）。
- 保存成功后的提示改为供应商页自己的结果提示，并提供「查看模型线路」按钮切换到模型线路分类；不再静默跳到另一个 tab。
- 列表行、编辑器、目录三态沿用原有 DOM 结构与样式类，仅去掉 tab 包裹层。

### 3. 模型线路页

- 保留原有能力：家族筛选导航（全部线路 / DeepSeek / Kimi / GLM / Auto）、线路卡片（启停、默认标记、模型清单、上移下移、设为默认、编辑、删除）、清空默认线路、失败自动切换开关、线路编辑器（所属中转、模型清单、单价与缓存价、上下文与输出上限、图片能力、推理等级、能力开关）与价格导入。
- 没有任何供应商时显示「还没有供应商」卡片，按钮改为跳转供应商分类；不再提供页内切 tab。
- 供应商被剔除的模型提示改指向「供应商」页。

### 4. 入口、限制与键盘

- 「管理提供商」类入口（侧栏设置菜单之外的模型选择器底部、聊天区空提供商提示、主页模型目录错误态与「去更新」）统一打开供应商分类。
- 运行中、会话加载中、配置读取中同时限制供应商与模型线路两个分类，限制原因分别写明是供应商配置还是模型配置；受限时定向打开仍回落到外观。
- 编辑子页打开期间外层分类切换继续禁用；Esc 先执行子页返回，再关闭设置；保存 pending 期间沿用现有关闭与 Esc 保护；删除确认层不向外传播取消。
- 分类切换会卸载当前子页，未保存的编辑随之丢弃，与既有 tab 行为一致（编辑期间本就无法切换）。

### 5. 代码与样式

- 新增 `src/components/ProvidersSettings.tsx`（供应商页）与 `src/components/RoutesSettings.tsx`（模型线路页，由 `FamiliesSettings.tsx` 拆出并删除原文件）。
- 新增共享模块：`src/chat/useModelCatalog.ts`（官方页面 + models.dev 目录与最新模型来源）、`src/components/settingsEditor.ts`（草稿态、pending/error、删除确认、列表↔表单焦点交接、对外 locked 上报）。
- CSS 把 `.family-settings-content` 改为两页共用的 `.settings-editor`，并删除已无引用的 `.dialog-tabs` / `.dialog-tab*` / `.family-tab-content` 规则；不新增颜色、字号、圆角硬编码。

# 会话统计

入口：**设置 → 对话统计**。页面顶部按工作台场景切片，默认跟随打开设置时的工作台：**💻 代码工程**（Code 工作台）、**🎨 设计生成**（Design 工作台）和 **🌐 全部汇总**；进入页面后可随时切换，不需要重新打开设置。

- 代码工程：KPI 只保留会话请求、消耗 Tokens、已知费用和缓存命中率；趋势与日历只能切 Tokens / 请求；明细只含模型请求，不再出现图片或视频行。
- 设计生成：KPI 为生成图片、生成视频和生成任务（有生成费用时改为费用）；趋势与日历只能切图片 / 视频；明细换成「时间 / 类型、项目、服务、模型、状态」的生成记录表头。
- 全部汇总：六个 KPI 的全局总览，趋势、日历和明细混合展示请求与生成记录。

每个场景下方都有趋势、活跃日历和可分页的明细，也可以按项目、提供商或模型汇总。项目与提供商可交叉筛选；点击汇总行的项目/提供商名称也会应用筛选。统计默认最近 30 天，可换到最近 7 天、90 天或全部时间。

活跃日历固定显示以今天为截止的最近 53 周（约一年），格子宽度随卡片自适应，不产生横向滚动。它只跟随项目与提供商筛选（以及场景切片），不随时间范围收缩；没有记录的日期保留低饱和度占位底色。

## 统计口径

- 读取当前工作区所索引的本地 pi 会话，包括归档和隐藏项目。计入日志实际保存的模型响应、含用量的中止请求和有模型标识的失败记录；不推断未落盘的上游重试。分支实际发生的请求仍计入，复制到 fork 的同一个 pi 条目不重复计算。
- Tokens = 新增输入 + 输出 + 缓存读取 + 缓存写入；缓存命中率 = 缓存读取 ÷（新增输入 + 缓存读写）。用量缺失时显示「—」，不会从正文猜算。
- 费用优先使用响应当时的路线价格快照；没有匹配快照且能唯一匹配当前提供商和模型时，按现价估算并显式标注。未定价请求不按零元处理，币种不合并，金额不是账单。
- 生成只计完成记录，不混入会话成本或 Tokens。已从画廊移除的成功图片仍计入，导入作品和失败任务不计。视频若提供商已确认生成完成，即使本地下载失败仍计一条。优先用完成时间，旧记录没有完成时间时用提交时间。独立配置的图片/视频服务分别按各自的服务 ID 归组，不靠同名猜测是否同一提供商。
- 仅从应用既有日志和生成任务记录读取统计元数据；不扫描项目文件、不返回聊天正文、提示词、素材或密钥，也不修改历史。日志缺失、损坏或不匹配时报告读取缺口。打开页面或点击刷新读取最新落盘记录。

## 验证

- `npm test`、`npm run build`、`npm run check:ui`、`npm run test:styles`。
- `cargo check --manifest-path src-tauri/Cargo.toml`；`cargo test --manifest-path src-tauri/Cargo.toml --lib`。
- `npm run dev -- --port 1421` 后运行 `node tests/session-statistics.browser.mjs`：浅/深主题、三种场景的 KPI 与表头、场景默认选中、窄窗、归档、分组、交叉筛选、图表键盘操作、日历悬浮卡片与固定年份网格、分页、空状态和读取失败恢复。截图在 `dist/session-statistics/`。
- `npm run test:cdp -- --statistics`：临时 WebView2 和 pi 数据目录，真实 pi 通过本地 mock 返回用量，合并已有归档、图像及视频任务记录，检查 Tauri IPC 不返回敏感内容。有本机开发服务器占用 1420 时，使用 `SKIFF_CDP_BINARY` 指定已构建的 debug 可执行文件，测试会复制到临时目录运行。截图在 `dist/cdp-session-statistics.png`。

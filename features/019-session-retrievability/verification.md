## 实现

- 本地标题采用首条用户正文的 32 个 Unicode 字符摘要，归一化空白；图片单独输入有回退标题。手动改名优先，重名使用 createdAt / 稳定 ID 后缀。侧栏和主页共用最后完成回复的 routeSnapshot 与别名口径，原始模型 ID 保留在悬停信息中。
- 新增受限原生命令 `set_history_workspace` / `read_session_history`。仅允许工作区登记的会话，文件必须位于 pi agent 的 sessions 目录内；检查规范化路径、普通文件、JSONL 格式、header/cwd、v1/v2/v3 分支、完整行和读取前后版本。单文件读取上限 64 MiB，越限显示历史不可读取；不截短后当作完整结果。
- 搜索覆盖未访问会话与当前分支压缩前的 user/assistant 正文，不启动索引进程、不调用 switch_session。150 ms 防抖，跨查询共用最多 2 个读取槽；LRU 最多 50 会话 / 20 MiB，优先复用仍在缓存中的历史，淘汰不缩小检索范围。
- 结果区分标题/正文。稳定 entryId 或角色、时间戳、正文指纹与重复序号定位；分支版本变化拒绝旧定位。当前消息展开、滚动并显示带高亮的命中原文；压缩前命中打开只读历史。已有高亮在消息身份变化后失效，避免复用 history_N 时标错消息。正文结果每次先展示 200 条，可继续展开，扫描覆盖全部会话。
- 线路授权、自动切换、路由审计及配置更新迁到会话常驻控制器，保留 owner/generation 与扣费账户边界。后台状态按需要确认、失败、运行、空闲排序，角标有符号与可访问名称；标题栏排除当前会话，分别汇总运行和待处理数量。
- 移除侧栏重复最近列表，保留主页最近会话；日期按本地日历分组并计数，固定会话去重。新聊天直接进入当前项目/模型的空白草稿，非空草稿不复用。
- 普通草稿保存到独立 IndexedDB，workspace v1 仅增加可选元数据。180 ms 保存防抖、导航刷新、重载生命周期内直接启动事务；单附件 / 单草稿 / 全库按 1 / 4 / 20 MiB 的实际序列化字节计量。容量及配额失败降级元数据并提示；重载后的缺失附件阻止发送，重新添加同名附件后解除。发送失败保留、接收成功仅清已提交内容；归档、删除、移除项目及孤立记录清理阻止迟到写入复活。018 编辑定位/分支/先前草稿字段已预留。

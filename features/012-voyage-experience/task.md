# 012 · 航行台速度统计、钓鱼等待态与上下文提醒

状态：已实施，验证记录见 verification.md。创建日期：2026-10-11。

## 背景与目标

航行台目前只显示实时船速，缺少本轮平均速度和最高速度。小船动画由整轮运行状态控制，即使等待模型响应、没有新 Token 且速度已经归零，小船仍在航行；仪表盘还会将低于 5 tok/s 的速度直接显示为 0。上下文目前只有 80% 和 95% 两档进度配色，缺少明确的文字提醒。

本 feature 补充本轮速度统计，用钓鱼小人表达任务仍在进行但暂时没有 Token 输出的中间态，并在上下文达到 90% 时提供不打断操作的持续提示。统计与状态同时适用于展开航行台和底部状态条，提醒在航行台折叠后仍然可见。

应用改动已实施，自动检查与浏览器模拟 QA 结果见 verification.md。沿用现有 Token 的 k / M 格式，不新增统计持久化字段或原生接口。

## 行为约定

### 1. 本轮速度统计

- 保留仪表盘实时船速，在仪表盘下方并排显示「本轮平均」「本轮最高」，单位为 tok/s，保留一位小数。
- 平均速度为本轮输出 Token 除以从提交到当前或结束的总耗时，包含思考、工具执行和等待时间。
- 运行中沿用思考文字与回复文字的 Token 估算；工具参数不计入实时文字估算。结束后优先使用本轮完整的实际 output usage 校正平均速度；实际 usage 缺失或不完整时保留估算并明确标注。
- 最高速度记录现有 500ms 滑动窗口经平滑后的速度峰值，标注为估算。最高速度数值不受仪表盘 300 tok/s 刻度上限限制，不通过最终 usage 校正产生的跳变计算峰值。
- 本轮结束后保留平均速度和最高速度，新一轮提交时重置。等待 pi 确认新用户消息期间，不将上一轮输出计入新一轮统计。
- 切换会话时清理采样与峰值。恢复历史时可以根据有效 output usage 和耗时计算平均速度；无法恢复的最高速度显示「—」，不伪造历史峰值。
- 没有有效耗时或可用输出数据时平均速度显示「—」，避免除零或非有限值；已开始计时且尚无输出时可以显示 0.0 tok/s。

### 2. 航行、钓鱼与停泊

- 将“任务仍在运行”与“正在产生 Token”分开。提交后立即进入等待态；收到思考或回复 Token 后航行，连续 800ms 没有新增 Token 后进入钓鱼态，避免短暂断流引起闪烁。
- 钓鱼只表达无新 Token 的等待。即使模型仍在思考，只要思考文字持续输出，就正常航行并计算速度。
- 钓鱼态实时速度归零，隐藏尾流、停止海浪横移。使用与现有小船风格一致的内联 SVG 绘制坐在船上的小人、鱼竿和浮标，小人随小船轻晃，浮标缓慢浮动。
- 收到新 Token 后收起钓鱼姿态，恢复航行及尾流。任务结束、取消或失败并停止运行后进入静止停泊态。
- 文字根据当前消息与工具状态区分「思考中」「工具执行中」「等待响应」；信息不足时使用「等待响应」，不将所有等待推断为思考。持续输出思考文字时可以同时显示「思考中」和航行动画。
- 移除低于 5 tok/s 强制显示为 0 的规则，让低速输出也有对应读数和航行状态。
- 右侧栏与底部状态条使用同一活动状态。上下文压力独立展示，不再用“已到港”覆盖任务的实际活动状态。
- 遵循系统“减少动态效果”设置：禁用循环动画，保留静态钓鱼图、文字和必要颜色提示。

### 3. 上下文 90% 提醒

- 使用现有上下文用量和当前模型上限计算比例，以实际比例而非四舍五入后的显示值判断阈值。沿用现有用量更新时机，不用实时输出估算代替已报告的上下文。
- 比例达到 90% 时，在底部状态条上方显示持续提示：「上下文已使用 XX.X%，建议新开会话。」包含图标、文字和警示色，展开或折叠航行台时都可见。
- 比例恰好为 100% 时显示「上下文已达到上限，建议新开会话。」；超过 100% 时显示「上下文已超出上限（XX.X%），建议新开会话。」
- 在展开的航行台内同步显示简短提醒。仅底部提示使用温和的无障碍状态播报，避免两个区域重复播报。
- 上下文或有效上限未知时不显示提醒，比例下降到 90% 以下时自动消失；切换模型后按新上限重新计算。
- 沿用现有 80% / 95% 进度配色：80% 起 warning，超过 95% 为 critical。新增 90% 文字提醒独立于配色分档。
- 不弹确认框或一次性通知，不自动新建或切换会话，不阻止用户继续操作。

## 验收矩阵

| 场景 | 必须验证 |
| --- | --- |
| 提交后等待首 Token | 立即进入钓鱼等待态；新轮统计已重置，不读取上一轮输出 |
| 思考文字持续输出 | 正常航行，思考 Token 参与速度估算，文字可以显示“思考中” |
| 回复文字持续输出 | 实时速度更新，平均与最高速度在仪表盘下方可见 |
| 工具执行但无 Token | 超过无输出宽限后钓鱼，文字显示“工具执行中”；耗时仍计入平均值 |
| 连续无输出不足 800ms | 不因短暂断流切换钓鱼姿态 |
| 连续无输出达到 800ms 后恢复 | 先进入钓鱼并归零，收到新 Token 后恢复航行，最高速度保留 |
| 低于 5 tok/s 的持续输出 | 按一位小数显示实际估算速度，不再强制归零 |
| 多段 assistant 与工具步骤 | 本轮输出不重复计数，等待时间纳入平均值，峰值跨步骤保留 |
| 最终 usage 到达 | 使用完整实际输出校正平均速度，不将校正跳变记为峰值；缺失时说明估算 |
| 正常结束、取消、失败 | 运行结束后静止停泊，保留有效统计，无计时器持续修改已结束数据 |
| 新轮提交及会话切换 | 新轮清零、旧轮数据不污染；会话切换清理采样和峰值 |
| 恢复历史与数据不足 | 有 usage 和有效耗时可算平均值；无法恢复的最高速度、无有效分母的平均值显示“—” |
| 上下文 89.9% / 90% / 95% | 89.9% 无文字提醒；90% 起提醒；95% 保持既有配色边界语义 |
| 上下文等于 / 超过 100% | 分别显示达到或超出上限文案，不覆盖任务活动状态 |
| 未知上下文、模型切换、比例下降 | 无数据不提示；按新上限更新；低于 90% 自动移除提醒 |
| 航行台折叠与窄屏 | 底部提醒持续可见，统计与文字无溢出，展开详情仍可访问 |
| 减少动态效果 | 禁用轻晃、尾流和海浪动画，静态图与文字仍能区分等待和停泊 |

# Git Tree · 2026-10-29

「文件」面板顶部依次为「文件」「Commit」「Git Tree」三个 Tab：Commit 处理未提交变更，Git Tree 浏览历史。顶部统一为 44px 项目 Header 和 40px Tab 栏，Tab 下方直接展示内容，不额外占用工具栏行。各 Tab 的折叠、刷新或 Update Project 操作由原面板管理状态，显示在 Header 项目选择器右侧，最小 200px 侧栏也能完整显示三个标签。项目触发器使用透明背景、24px 文件夹徽章与紧凑下拉箭头，悬停、键盘聚焦或展开时才显示柔和底色。沿用 032 的项目选择器，浏览其他项目不改变当前聊天。

桌面使用三栏：

- 左栏：所有分支、HEAD、本地分支、按远程分组的远程分支、标签；支持名称过滤。
- 中栏：按真实父提交关系绘制的拓扑图、提交标题、作者和精确到分钟的日期时间（24 小时制）。提交列表不显示 HEAD/分支标签，引用信息保留在分支树和提交详情中。点击或上下方向键选择提交。文本搜索匹配已加载的标题、作者、hash；搜索结果隐藏连线，避免把不相邻的提交错误连接。
- 右栏：提交的变更文件树、完整说明、作者、日期、hash 和父提交。点击文件读取该提交的历史 Diff，与当前工作区内容无关。合并提交默认与第一父提交比较，初始提交与空树比较。

Git Tree Tab 在侧栏显示分支与标签筛选，在主区保留宽幅提交图与详情；切回文件或 Commit 恢复文件预览及其模式、滚动位置，文件树展开状态、提交草稿与勾选也保留。主导航「文件」按钮记住第三个 Tab，点击当前入口仅收起或展开侧栏。兼容已有 `skiff.workbench.v1` 的 `git-tree` 选择。

切换 Tab 或返回对话时保留 Git Tree 的列表、详情、搜索和滚动位置；再次进入复用已加载历史，不重新读取未变化的查询。历史缓存按项目、分支筛选、分页上限、HEAD 和刷新版本隔离；HEAD 变化、提交或主动更新后重新读取，同一查询更新期间保留原内容，避免先清空再显示。

提交详情右侧的文件树默认高度不超过 200px（小窗口为可用高度的 35%），下方说明独立滚动。两区间的横线支持上下拖动、方向键及 Home/End 调整，保留至少 120px 给说明；高度偏好保存在 `skiff.git-tree.files-height.v1`，切换提交或重启后保留。

提交详情的「变更文件」标题右侧提供「全部展开 / 全部折叠」，文件 Tab 的 Header 使用相同的双箭头操作。提交文件树一次切换所有层级；项目文件树按需逐步读取子目录，全部折叠、手动切换目录、刷新或切换项目会停止尚未完成的自动展开，迟到的读取不会重新展开目录。

窄屏使用分支抽屉，提交记录和详情上下排列。聊天组件保持挂载，「返回对话」保留会话与已打开文件，主区「分支」按钮可重新展开三个 Tab；Git Tree 的项目请求、提交详情和 Diff 均忽略已失效的响应。

提交列表中「提交信息 / 作者 / 日期」之间提供贯穿列表的拖动分隔线。两条边界分别调整提交信息列和作者列，所有行同步对齐；支持方向键微调和 Home/End 调至边界。列宽保存在 `skiff.git-tree.columns.v1`，切换项目与重启后保留。窄屏保留各列，宽度不足时在列表内横向滚动。

历史读取接口在 `src-tauri/src/git_history.rs`，复用既有项目目录与仓库识别。项目为仓库子目录时，历史和文件限定到该目录并显示范围。浏览历史只读，不 checkout、fetch 或改写暂存区。完整 hash 校验、字面路径参数、禁用 external diff/textconv；新增接口不需要扩展 capabilities。

每次加载 100 条，可继续加载到最近 1000 条。远程分支来自本地已有的远程引用。历史 Diff 截断上限为 2 MB，二进制单独提示。非仓库、空历史、失效分支和读取失败有对应状态及刷新/重试入口。

## Update Project

`Update Project` 使用左下箭头，同一时刻只显示一个入口：分支侧栏（含窄屏抽屉）展开时位于侧栏 Header，收起时位于历史工具栏。更新当前浏览项目所在仓库的**当前检出分支**，不受左侧历史筛选影响，不切换分支。Commit 的分支图标、Changes 折叠箭头与文件树顶层行使用距面板左侧 10px 的基准线。

- 不弹 Merge/Rebase 策略对话框。显式 fetch 当前分支的 upstream 后，只允许 fast-forward；不生成 merge commit，不 rebase，不 reset，不自动 stash。
- 已同步显示「已是最新」；本地领先显示「无需拉取」；本地与远程分叉时更新远程引用，但停止本地更新，提示用 IDE/命令行处理。
- 检查整个仓库（含项目目录之外）的未提交/未跟踪改动和未完成 Git 操作。detached HEAD、未配置 upstream、网络/认证错误均给出原因。fetch 结束后重新检查 HEAD、分支、跟踪配置和工作区；禁止覆盖忽略文件。
- 原生实现在 `src-tauri/src/git_update.rs`，与提交/恢复共用写入锁。网络操作不弹终端凭据输入，超时 120 秒；不把可能包含凭据的 transport stderr 输出到 UI。复用现有 Git 进程权限，无需增加 capabilities。
- 入口位置切换时保留运行状态，重复点击无效；切换项目后的迟到结果只归属原项目。更新成功刷新历史、Git 状态、文件树及已打开的文件预览。

验证：新增 4 项 Rust 临时远程仓库测试通过，覆盖快进/最新/领先/分叉、改动和操作拦截、fetch 后竞态、忽略文件保护、失败时的状态保持与错误脱敏。`node tests/git-update.browser.mjs` 验证单一入口随侧栏开合切换、请求互斥、反馈、文件树刷新、跨项目结果隔离，浅深主题均通过。`npm run test:cdp` 的临时本地远程仓库真实验证未提交改动拦截、快进更新和分叉保留本地提交；未访问开发者远程仓库。截图 `dist/git-update-cdp.png`、`dist/git-update/`。

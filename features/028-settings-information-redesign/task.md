# 028 · 设置三模块信息与交互整理（第一期）

状态：已完成。创建日期：2026-10-19。完成日期：2026-10-19。验证见 [verification.md](verification.md)。

来源：[设置改版预览](../../tests/settings-redesign-preview.html)及需求评审。承接 025 供应商独立入口与 027 模型家族设置；第二期见 [029 · 设置批量管理与使用记录](../029-settings-management-tools/task.md)。预览是视觉参考，涉及价格、默认路线、模型范围及筛选的冲突，以本文行为约定为准。

## 背景与目标

设置已拆成供应商、模型、路线三个页面，但列表信息密集、路线操作分散，用户难以判断模型接到哪里、为何不可用。此次整理信息层级与操作入口，同时修正模型页测试没有使用实际调用 ID 和供应商协议的问题。

产品文案沿用现有「供应商 / 模型 / 路线」。供应商管理接入信息与模型接入清单，模型页管理家族展示清单，路线管理具体模型的价格与能力。搜索、折叠、展示标记不能改写配置、模型 ID、默认路线、会话固定路线或故障切换顺序。

## 范围与行为约定

### 1. 供应商列表与编辑器

- 列表工具条包含搜索、全部/启用/停用筛选和右侧添加按钮；默认全部，保留配置原顺序。搜索按名称与脱敏端点进行不区分大小写的子串匹配，不搜索密钥。状态计数基于搜索匹配结果、应用状态筛选之前的集合。
- 行内显示名称、来源类型、脱敏端点、协议、已配置且未剔除的去重模型数、启停开关及编辑入口；不再同时展示重复的启用/停用标签，不在列表常驻密钥指纹。
- 来源使用现有预设匹配结果，区分官方直连、中转、本机、自定义；匹配不到归为自定义，不能把未知端点推断成官方。第一期仅展示标签，不新增来源配置字段或分组控件。
- 停用行使用现有次级文字与状态样式，不整行降低透明度；开关和编辑入口保持可辨识、可操作，并有明确的无障碍名称。
- 编辑器主线保留名称、可选择的 API 协议、密钥、端点、模型及测试。扣费账户、超时和已保存密钥指纹收进「高级选项」；摘要提示已设置账户或非默认超时，折叠内字段报错时自动展开并聚焦。
- 保留全部协议、本机无密钥配置、获取模型、单模型测试、批量测试、取消、剔除/恢复与新增供应商必须通过连接测试后才能保存的规则。
- 供应商模型表目前已是「模型 ID / 上下文 / 显示名 / 测试」，不重复进行价格列迁移。上下文和显示名继续编辑同一份路线模型数据；保存供应商必须保留未编辑的价格、能力、推理等级、路线顺序及剔除模型信息。

### 2. 模型可用性、映射与测试

- 保留家族标签页、编辑家族模型、联网更新和 Auto 卡片。模型列表读取现有可编辑家族清单：自动更新最多保留两个自动模型，手动模型继续展示且不被刷新覆盖；不在渲染阶段强制截成两个。
- 可用路线数只计入供应商与路线均启用、确实包含目标模型且模型未被剔除的路线。Auto 也必须至少包含一个未剔除模型，不能仅按开关计数。
- 每个模型显示「未指定路线时优先：供应商名」，由该模型的实际可用候选计算：可用且支持目标模型的家族默认路线优先，否则按现有路线顺序。提示不代表已有会话的固定路线；无候选显示「未接路线」并提供入口。
- 展示 ID 与真实调用 ID 的对应关系沿用现有目录匹配规则。选定路线后优先精确匹配 ID；仅有别名匹配时按路线模型原顺序取第一个未剔除匹配项，并在测试目标中展示实际 ID。仅用于设置页解析，不改聊天与故障切换的精确 ID 匹配规则。
- 映射表保留真实调用 ID、剔除/停用原因；家族默认与各模型优先路线分开标识，不能给不支持该模型的单元格标成优先。内部标识使用供应商/路线 ID，不依赖显示名称。
- ★ 只表示用户设置的家族默认路线，并配文字或可访问说明；第一期不引入新的模型推荐评分，不凭列表位置或任意 ID 后缀推断「旗舰/快速」。自动/手动仍表示清单来源。
- 修正单模型测试：传递选中供应商的协议、端点、超时和匹配到的真实调用 ID。状态保留供应商、实际模型、成功/失败与延迟信息；无候选禁用测试。取消、卸载和配置变化后，迟到结果不能写回新目标。

### 3. 路线列表与操作

- 保留家族导航；顶部增加搜索和「仅看可用」筛选，默认关闭。搜索匹配供应商名、模型真实 ID 与显示名；可用定义与模型页一致。家族计数及卡片提示区分当前显示数量与配置总数量。
- 路线开关始终表达路线自身 enabled。供应商停用、所有模型被剔除、未配置模型等阻断原因单独显示；不能把这些情况伪装成路线开关关闭。
- 模型摘要最多显示两个该路线实际配置的模型，优先匹配当前家族清单，剩余按路线原顺序补足；历史模型与手动模型均可进入摘要。超过两个提供「查看全部 N 个模型」，展开显示全部真实 ID 与状态；不修改或删除隐藏模型。
- 列表价格摘要统一写「按模型计价」；展开后逐模型显示输入/输出单价、币种与每百万 token 单位。缓存价继续在线路编辑器查看与编辑，不使用一组价格代表整条路线。
- 默认路线前置 ★ 与「默认」说明。右侧操作收进更多菜单，包含编辑、设为默认、上移、下移、删除；默认项保护和禁用原因继续可见。清空默认仍是带说明与确认的显式操作，不自动替用户清空。
- 第一期开关、默认值、删除和排序继续使用既有 RPC。上移/下移按完整家族顺序运行，仅在无搜索且关闭可用筛选时可用；受限时提示清除筛选。拖动排序由第二期实现。
- 自动故障切换开关保持全局含义，不随家族或列表筛选改变范围；保留同实际模型 ID、能力要求、后续路线顺序及跨账户确认规则。

### 4. 跨页导航、焦点与视觉

- 共用工具条的间距、对齐和交互样式，但不强制给少量模型的页面增加搜索、状态或排序控件。
- 扩展设置页内部定位参数，支持 familyId、relayId、routeId。供应商保存成功后可进入对应家族及具体路线；涉及多家族时按家族提供入口。模型页未接路线可进入对应家族，不能误开其他供应商的路线。
- 编辑草稿期间不提供直接丢弃草稿的跨页跳转；显示「保存后可编辑路线」，保存成功后再使用定位入口。遵守现有运行中、加载中、pending 与编辑态分类锁定。
- 更多菜单支持键盘、Esc 与关闭后焦点恢复；Esc 依次关闭菜单/确认层、返回编辑器、关闭设置，不越级传播。筛选导致原行消失时，焦点回到相应工具条。
- 复用 tokens、Button、IconButton、Disclosure 等现有体系，提供浅/深主题；窄窗下工具条换行，映射表必要时在局部滚动，不挤压整页或遮挡保存按钮。

## 接口与数据边界

- 主要涉及 `src/components/` 的三个设置组件及设置导航、`src/chat/` 的模型解析和测试适配、共享 UI 样式与 mock bridge。
- 模型测试回调补齐已有 RelayProtocol 参数；内部导航增加精确定位信息。无须新增原生命令或迁移 `skiff-families.json`。
- 共享可用性/测试目标派生逻辑，避免三页各算一套；不将家族展示清单复制成第二套实际接入配置。
- 不新增批量管理、测试持久化、最近使用记录、展示排序偏好或拖动依赖，这些全部归第二期。

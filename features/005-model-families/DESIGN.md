# 005 · 模型家族与提供商渠道

固定 DeepSeek、Kimi、GLM 三个家族。每个家族配置多个渠道，当前选择由家族和渠道共同确定；渠道实际调用的模型 ID 可以不同。显示名、地址、密钥、输入/输出单价、币种、默认最大输出、流式/工具/视觉能力、超时和启用状态分别保存。`providers` 数组顺序就是家族内优先级，默认渠道通过 `defaultProviderId` 指定。

## 交互

- 输入框模型按钮显示「家族 · 渠道」，浮层按家族分组，展示渠道名、实际模型 ID 和每百万 Token 单价。支持搜索、方向键、Enter、Escape，底部入口打开管理提供商。浮层定位限制在窗口边界内。
- 聊天标题同样显示「家族 · 渠道」。默认最大输出在提供商表单中配置，位于超时附近；选择器仅保留模型列表和管理入口。
- 单价币种为人民币或美元，默认人民币，不做汇率换算。费用 ≥ 0.01 时显示两位小数，更小时保留四位有效数字并省略末尾零；输入/输出单价都为零时显示「—」，提示「未配置单价」。右栏分别展示本轮费用和当前会话累计，不同币种分别累计。
- 设置保留三个固定家族卡片，支持添加、编辑、启停、上下移动、默认渠道与删除；家族有配置后至少保留一项。跨家族克隆复用地址、密钥、价格和能力，需要另填当前家族的模型 ID 与显示名。
- 连接测试经 Rust 发送 `max_tokens=1` 请求，返回完整响应读取耗时、HTTP 状态及最多 200 字错误摘要；响应读取有大小限制，密钥从摘要移除。列表隐藏密钥，仅保留末尾四位；地址中的自定义路径隐藏。
- 网络错误、401、429、5xx 与超时显示 toast，同家族存在备用渠道时提供下一项快捷切换。可开启自动切换，默认关闭；切换完成后再次发送请求，不自动重复原请求。

## 配置与请求

- 新配置保存于 pi 配置目录下的 `skiff-families.json`。Windows 使用当前账户 DPAPI 加密密钥，其他平台暂不支持密钥保存，拒绝写入明文。
- 每个渠道投影为 `skiff-<family>-<id>` pi 提供商。`models.json` 保存价格与能力；`auth.json` 保存环境变量引用。密钥只在 Skiff 启动 pi 子进程时解密到其环境，不写前端持久化存储或扩展源码。
- Skiff 显式加载内置请求扩展，执行流式/工具能力开关、默认最大输出和整次请求超时；非流式 JSON 响应转换给 pi 的统一消息解析器。视觉能力由模型输入类型限制。用量来自 pi，费用按每条消息所属渠道的配置在本地计算：输入（包含缓存输入）/百万×输入单价 + 输出/百万×输出单价；推理量包含在输出中，不重复计费。不使用 pi 的费用估算。
- 配置更新等待会话空闲，再重启 pi 并恢复聊天与所选渠道。原渠道被删除或停用时选择对应默认项。配置命令共享原配置锁，保存失败恢复家族、模型与凭据文件；损坏 JSON 或无法解密的密钥禁止覆盖。

## 迁移与兼容

首次读取将已有 OpenAI 兼容 DeepSeek / Kimi / GLM 配置迁入对应家族，显示名以「默认」开头；同一渠道的多个模型迁为独立项。保留上下文上限、输出上限、推理与兼容参数，不将其他模型错误归为 DeepSeek。已有家族文件不会重复迁移。

旧提供商读取命令和原模型条目保留一个版本，已迁移密钥的明文副本改为子进程环境变量引用。因此应通过 Skiff 启动这些渠道；单独启动 pi 时不会获得 Skiff 解密的密钥。环境变量形式的旧凭据在迁移时解析，命令形式的凭据保留原配置并报告需要手动调整。
